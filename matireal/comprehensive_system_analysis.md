## 🏗️ ארכיטקטורת המערכת החדשה

### 1. **מנוע הליבה: `generate_course.py`**

**תכונות מתקדמות שהתגלו**:

#### 🧠 **"הקומפס הפדגוגי" (Pedagogical Compass)**
```python
def build_pedagogical_narrative(analysis, num_sessions):
    """
    The "Pedagogical Compass". This function organizes the raw sections
    into a coherent course flow.
    """
```
- **חדשנות**: אלגוריתם חכם שמארגן תוכן לפי עקרונות פדגוגיים
- **לוגיקה**: מיון אוטומטי לפי מילות מפתח (מבוא → ליבה → מתקדם)
- **גמישות**: התאמה דינמית למספר מפגשים

#### 🤖 **שילוב AI מתקדם עם DeepSeek**
```python
def call_language_model(prompt_text: str, api_key: str, system_prompt: str, context: str = "") -> str:
```
- **העשרת תוכן**: יצירת תיאורים ומטרות למידה באופן אוטומטי
- **התאמה תרבותית**: כל התוכן נוצר בעברית
- **Fallback חכם**: אם ה-API נכשל, המערכת ממשיכה עם תבניות

#### 📊 **מערכת צפיפות מתקדמת**
- **Low Density**: פרויקט גמר בלבד (100% משקל)
- **Medium Density**: פרויקט + בוחן (80% + 20%)
- **High Density**: מטלות שבועיות + בוחן + פרויקט (10% + 20% + 70%)

## 🔄 זרימת העבודה המלאה

### שלב 1: **ניתוח המדריך** 📖
```
HTML Guide → BeautifulSoup Parser → Structured Analysis
```
- **חילוץ מטא-דאטה**: כותרת, תיאור, מילות מפתח
- **זיהוי סעיפים**: כל H2 הופך למפגש פוטנציאלי
- **חילוץ "טיזרים"**: טיפים, אזהרות, סודות מקצועיים

### שלב 2: **בניית הנרטיב הפדגוגי** 🧭
```
Raw Sections → Pedagogical Compass → Ordered Learning Flow
```
- **סיווג אוטומטי**: מבוא, ליבה, מתקדם
- **חלוקה למפגשים**: התאמה למספר המפגשים הרצוי
- **איזון תוכן**: וידוא שכל מפגש מכיל תוכן מספיק

### שלב 3: **העשרה באמצעות AI** 🤖
```
Basic Content → DeepSeek LLM → Enriched Descriptions & Objectives
```
- **תיאורי מפגשים**: יצירת תוכן מעניין ורלוונטי
- **מטרות למידה**: ניסוח מקצועי במבנה סטנדרטי
- **התאמה תרבותית**: כל התוכן בעברית ברמה גבוהה

### שלב 4: **יצירת מטלות חכמות** 📝
```
Content Analysis → Density Logic → Tailored Assignments
```
- **מטלות מותאמות**: בהתאם לצפיפות הנבחרת
- **מחוונים אוטומטיים**: קריטריונים מבוססי תוכן
- **שילוב טיזרים**: שימוש בטיפים ואזהרות מהמדריך

### שלב 5: **יצירת JSON מובנה** 📄
```
All Components → JSON Schema → LMS-Ready Course File
```
- **תאימות LMS**: מבנה JSON מוכן לייבוא
- **מטא-דאטה מלאה**: תיעוד, גרסאות, מחבר
- **ולידציה**: בדיקת תקינות לפני שמירה
